    SyentheticBaseEvent
    -------------------------------------
        - react creates this SyentheticBaseEvent as a wrapper around the DOM Event object 
            - to provide a consistent interface for handling diff events accross diff environments 


    
    Controlled Form Element 
    ---------------------------
        - form / input element whose value is owned by React State 
        - value, onChange event on the form element that gets/updates the react state 

        Why: 
            - React State is the single source of truth 
            - you can transform as you type i.e. uppercase, strip space, format the value i.e. phone number 
            - easy to validate live
            - easy to reset or prefill

        cons: 
            - every keystroke it re-renders the owning component 
            - you must wire value + onChange on every field
